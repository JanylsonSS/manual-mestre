# Desafios de entrevista — Módulo 00

O módulo 00 não ensina código, portanto não tem desafios de código estilo entrevista — os volumes mínimos do §30 valem a partir do módulo 01 (registro: `DECISOES.md`, D-004).

O que este módulo oferece como treino de entrevista:

1. **O pitch do Atlas** (00.05, AP3) — 60 segundos cronometrados, reescrito por fase.
2. **As pegadinhas comportamentais** do banco [`perguntas.md`](perguntas.md): "quantas horas de curso?", "backend ou dados?", "foi você que fez?" — treináveis em voz alta desde já.
3. **O exercício de tradução de vagas** (00.02) — base para a pergunta "por que esta vaga?" de qualquer processo.

# Glossário PT/EN

Todo termo técnico ganha entrada de 1 parágrafo na primeira ocorrência no manual (§12.3). Ordem alfabética.

| Termo (PT) | Termo (EN) | Definição | Primeira ocorrência |
|---|---|---|---|
| API | API (Application Programming Interface) | Contrato pelo qual sistemas conversam entre si; a entrega típica do backend. | 00.02 |
| Backend | backend | O lado do sistema que o usuário não vê: recebe requisições, aplica regras de negócio, fala com o banco e responde. | 00.02 |
| Caixa-preta | black box | Padrão do manual para usar, de forma controlada, um conceito que só será explicado depois — sempre com a promessa do capítulo que o abre. | 00.01 |
| Checkpoint | checkpoint | Ponto de verificação com critério objetivo que decide se você avança (CP1 por capítulo, CP2 por módulo, CP3 por fase). | 00.01 |
| Curva do esquecimento | forgetting curve | Queda acelerada da memória de algo recém-aprendido quando não há reforço — o fenômeno que a revisão espaçada combate. | 00.04 |
| DevOps | DevOps | Ofício que leva código do repositório à produção e o mantém vivo: empacotamento, servidores, automação, monitoramento. | 00.02 |
| Engenharia de dados | data engineering | Ofício que constrói e opera as esteiras que extraem, transformam e entregam dados confiáveis. | 00.02 |
| ETL | ETL (Extract, Transform, Load) | Esteira de extração, transformação e carga de dados; sinônimo prático: pipeline de dados. | 00.02 |
| Ilusão de fluência | illusion of fluency | Sensação de domínio produzida por reconhecer um conteúdo ao vê-lo — sem conseguir produzi-lo do zero. | 00.01 |
| Interpretador | interpreter | O programa que lê arquivos Python e os executa; a peça central do ambiente. | 00.03 |
| PATH | PATH | Lista de pastas onde o sistema procura executáveis pelo nome; a busca para no primeiro encontrado. | 00.03 |
| Pipeline de dados | data pipeline | Ver ETL. | 00.02 |
| Prática de recuperação | testing effect / retrieval practice | Puxar informação da memória (com esforço) fortalece mais que reler; base dos flashcards e exercícios do manual. | 00.04 |
| Terminal | terminal / command line | Interface de comandos por texto; onde scripts são executados e ferramentas são operadas. | 00.03 |
| Flashcard | flashcard | Cartão de pergunta e resposta usado na revisão espaçada para recuperação ativa da memória. | 00.01 |
| Revisão espaçada | spaced repetition | Técnica que distribui revisões em intervalos crescentes (D+1, D+7, D+30, D+90) para fixação de longo prazo. | 00.01 |
| Trilha | learning path | A ordem oficial de estudo do manual: módulos 00→13, capítulos em ordem numérica. | 00.01 |
